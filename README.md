# 职航罗盘 · 学生职业规划大数据平台（zhihang-luopan）

用公开采集的真实招聘数据，帮学生回答四个贯穿大学三年的问题：
**市场在要什么（① 市场全景）→ 学校教什么（② 方向画像）→ 我差在哪里（③ 我的定位 → ④ 差距路径）→ 我接下来做什么（⑤ 成长档案 → ⑥ AI 顾问）**。

应用对象是**学生个人**（不是教务）：不做面向教务处的管理看板，不产出面向管理者的报表；
屏幕上的每一个数字，都要能变成学生今天就能做的一个动作。
工程能力（采集入库 / 技能标注 / 数据规范）收进 ⑧ 工程后台，不进学生动线；
⑦ 求职实战是学生动线的最后一步：JD 体检 → 简历技能段 → 模拟面试 → 投递清单。

> 本项目从 `gkzp`（AI 增强版）复制而来，**原项目 `gkzp` 与 `gangke-zhaopin` 均保留未动**；
> 本次大改前的代码备份在 `docs/_backup_20261104/`。
> 本版改动：**① 学生端五屏重构**（市场全景 / 方向画像 / 我的定位 / 差距路径 / 成长档案）、
> **② Coze 双引擎智能体**（上下文注入式 RAG + 对话式规划 + 规划书工作流 + 离线规则兜底）、
> **③ 成长档案**（定位快照、跨学期叠比、命中率成长曲线）、**④ 多专业**（9 个专业可选）。


## 快速开始

双击 **`启动_职航罗盘.bat`**（第一次自动建环境、装依赖），浏览器打开
`http://localhost:8520`（端口被占自动换 8521 / 8522；已开放局域网访问，
同一 WiFi 下的手机也能打开，用手机号注册登录即是完整网站体验）。

**账号与登录（网站首页）：**
打开就是产品首页（平台介绍 + 实时数据 + 登录注册卡）。**手机号 + 验证码**注册、登录，
不用记密码；验证码默认**演示模式**（不真发短信，直接回显在页面上），
配好短信网关后**自动切真实短信**——`core/sms.py` 内置阿里云 / 腾讯云 / Mob 免费短信 / 通用 webhook
四条通道，在「⑧ 工程后台 → 账号与登录 → 短信通道」填完保存、点「发一条测试短信」即可验证；
细节见 `docs/账号与登录说明.md`。
登录态写进 URL 的 `?t=`，刷新页面、换标签页都不掉，14 天过期。
首页还提供**演示账号一键进入**：`13800000001 林小雨`、`13800000002 陈子昂`、`13800000003 周乐`。

**一人一份档案（数据隔离）：** 账号 id 是数据隔离的唯一钥匙——成长档案、投递记录都挂在
`user_id` 上，换账号登录看到的是自己的记录；两个账号用同一个档案名也不会串。
档案名在侧边栏可改，改完即时存回账号，下次登录还在。

**学生动线（演示按这个顺序走）：**

1. 注册 / 登录（首页），侧边栏确认**档案名**与**我的专业**；
2. **① 市场全景**：市场在要什么——需求榜、共现网络、技能溢价（关联性估计已标注）；
3. **② 方向画像**：选岗位族看技能要求（样本 <100 条会提示"仅供参考"）+ 本专业课程覆盖四象限；
   覆盖率可切换口径：**全部岗位 / 只看本专业相关岗位族**（后者更公平，如大数据技术 28.8% → 53.9%）；
4. **③ 我的定位**：勾已会技能 → 命中率 + 差距清单 → 一键**存入成长档案**；
5. **④ 差距路径**：补课路线图 + 补课清单，每项差距挂着本专业课程名；
6. **⑤ 成长档案**：命中率成长曲线、两次定位自动对比（"命中率 41% → 63%，你正在变强"）+
   一键**生成本周成长周报**（本周补了什么、下周动哪项）；
7. **⑥ AI 顾问**：Coze 对话（上下文注入式 RAG）+ 一键生成五节职业规划书 +
   学生成长版九节点流程引擎（平台引擎工作台：市场要什么 → 课程教什么 → 我差在哪 → 先补哪个）；
8. **⑦ 求职实战**：JD 透视镜（粘贴任意 JD → 会/缺/先补，可再贴两条做**多 JD 对比**，
   分清"通用门槛"与"差异化要求"）→ 简历技能段生成器 → **模拟面试 · 数字人陪练**
   （SVG 数字人逐题对话 + **开口说话**（在线/离线双通道，断网照常出声）+ **学生语音作答**
   （本地离线识别，说完自动提交）+ **随时向面试官提问** + 智能追问 + 四维评分 + 书面反馈，
   可演示一键跑完）
   → 本周投递行动清单 → **投递记录与转化**（投了多少家、几次约面）；
   ④ 差距路径底部附**本周任务卡**：学哪章、练什么、交什么、预期命中率到多少。

**工程后台（⑧）**：采集入库（MySQL 双写、断点续采）、技能标注（三通道归一 + 抽检 κ）、
数据规范与指标台账。

**答辩两件套**：
- **开发者视图**：未登录首页右上角「🛠 开发者入口」，名单内账号登录后自动带工程后台
  + 学生端全部页面；学生账号登录只见学生端七屏；
- **演示账号登录**：`13800000001 林小雨`（AI·数据分析，命中率 11% → 77%）、`13800000002 陈子昂`
  （大数据·数据开发，24% → 67%）、`13800000003 周乐`（软件·后端，19% → 46%），
  首页一键进入、退出后换号登录，直接展示"不同账号互不干扰 + 跨学期成长曲线"。
- **AI 事实校验**：规划书与顾问回答生成后，自动把文中数字与平台计算结果逐个比对，
  不一致就标"待核"——防幻觉不靠承诺，靠一道可见的闸。

## Coze 接入（约 30 分钟，可跳过）

把 `config/coze.json.example` 复制为 `config/coze.json`，填 token / bot_id /（可选）workflow_id。
三级降级自动兜底：**Coze 在线 → OpenAI 兼容接口（config/llm.json）→ 离线规则引擎**；
断网、没配 key 都能演示，离线回答与规划书里的数字全部来自平台真实计算，不失真。

## 数据与口径

- 岗位数据：智联招聘公开搜索页，无需登录；MySQL 主库 `jobs` 主键去重，`crawl_progress` 记断点，`crawl_log` 留流水；
- 分析读本地 SQLite 快照（毫秒级，MySQL 未启动也能演示），页面上有主库/快照对照与一键对齐；
- 课程覆盖权重 = 0.6 × 需求分位 + 0.4 × 溢价分位；同一技能被多门课覆盖时取最高分；
- 薪资溢价是**关联性估计，不是因果**；模型 R² 如实披露，样本门槛写死（≥25 条技能、总体 ≥200 条岗位）；
- 成长档案存 SQLite `career_snapshot` 表，按**登录账号 user_id** 隔离（历史无账号数据归 0 号，任何账号都看不到），跨学期叠比；
- 所有对外数字以 `docs/指标台账.md` 为单一事实源，页面「⑧ 工程后台」可一键重生成。
